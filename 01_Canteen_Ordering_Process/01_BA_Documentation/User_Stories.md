
# User Stories & Acceptance Criteria

## US-01 — Browse Menu
**As a customer, I want to browse categories and menu items so that I can quickly decide what to order.**

**Acceptance Criteria**
- Categories are clearly separated.
- Item name and price are visible.
- Customer can open an item to see details.
- A clear Add button is available.

## US-02 — Build Cart
**As a customer, I want to add items to a cart so that I can review my order before placing it.**

**Acceptance Criteria**
- Item quantity can be increased/decreased.
- Cart total updates correctly.
- Customer can remove an item.
- Cart shows total number of items and total amount.

## US-03 — Place Order
**As a customer, I want to confirm my order so that the canteen can start preparing it.**

**Acceptance Criteria**
- Customer sees a final order summary.
- Payment method is visible.
- Successful submission creates an order reference.
- Confirmation screen displays estimated preparation time.

## US-04 — Track Order
**As a customer, I want to see my order status so that I know when to collect it.**

**Acceptance Criteria**
- Status includes Pending, Preparing and Ready.
- Current state is visually highlighted.
- Order reference remains visible.

## US-05 — Manage Order Queue
**As staff, I want to see and update incoming orders so that preparation can happen in an organized sequence.**

**Acceptance Criteria**
- Orders are sorted by status/time.
- Staff can open order details.
- Staff can move an order through status stages.
