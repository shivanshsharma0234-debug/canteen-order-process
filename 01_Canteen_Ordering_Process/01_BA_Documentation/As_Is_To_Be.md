
# Process Mapping

## AS-IS

Customer → View Menu → Tell Staff Items → Staff Writes Order → Payment/Queue → Preparation → Customer Waits → Ask for Status → Collect

### Pain Points
- Manual order capture
- Repeated communication
- Queue uncertainty
- Limited status visibility
- Difficult peak-hour monitoring

## TO-BE

Customer → Browse Digital Menu → Add to Cart → Review → Submit/Pay → Confirmation → Staff Order Queue → Preparing → Ready Notification → Pickup

### Expected Improvements
- Structured order data
- Fewer handoffs
- Clear order status
- Better queue visibility
- Better foundation for reporting
